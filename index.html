05Process

How I work on data projects.

  1. Read the spec first

    Guidelines, examples, and edge cases before touching any task. Ambiguity gets flagged, not guessed.

  2. Calibrate early

    Small pilot batch, check interpretation, adjust — so the remaining work stays consistent.

  3. Self-QA before submit

    Re-read labels and rationales against the rubric. Clean formatting, no placeholders, on time.
