Portfolio V3

This site: a zero-dependency Node generator that builds a static portfolio from JSON and HTML sources, with validation, a light/dark theme, and no advertising trackers.

View the source Discuss a similar build

The problem

What needed to change

The previous portfolio was a single hand-edited HTML file. Case studies, project data, navigation, and metadata were duplicated across pages, so every content change risked an inconsistency or a broken link.

The build

What I made

A small Node build script reads JSON and HTML source files, validates required fields and statuses, and writes static pages to the repository root for GitHub Pages. The output has no framework runtime, no npm dependencies, and no build service. Theme preference is applied before first paint, navigation is shared, and the project library is filtered in plain JavaScript.

The source is public. The generated site is plain HTML, CSS, and a small amount of JavaScript; the build step exists to keep content and structure in one place.
