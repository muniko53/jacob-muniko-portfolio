Linklet Social Poster

A daily social media poster that drafts a Linklet listing post, sends it to Telegram for approval, and publishes to Facebook, Instagram, Pinterest, and TikTok.

Discuss a similar automation

The problem

What needed to change

A marketplace needs a consistent social presence, but posting every day by hand is easy to skip. Automating it without approval is worse: a bad caption or the wrong image goes out under the brand.

The build

What I made

A scheduled Node.js worker pulls a real listing image, generates a caption with Groq, and sends the draft to an admin on Telegram. Nothing publishes until the admin approves, edits, or rejects it. Approval sends the post through Zernio to the connected platforms, with preview and post-now modes for testing.

Working inventory

Tools used

  • Node.js
  • Groq
  • Zernio
  • Telegram Bot API
  • node-cron
