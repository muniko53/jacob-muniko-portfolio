# Jacob Muniko — Portfolio

Single-file static portfolio. No build step, no dependencies.

## Files

- `index.html` — the whole site (HTML + CSS embedded)
- `photo.jpg` — portrait used in About
- `Jacob_Muniko_Resume.pdf` — resume linked from Contact

## Preview

Double-click `index.html`, or serve locally:

```powershell
npx serve .
```

## Deploy

Drag this folder onto `app.netlify.com/drop`, or import it as a static project on Vercel / GitHub Pages.
