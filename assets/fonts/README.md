# Self-hosted fonts

The site serves these fonts locally so a visit does not make third-party font
requests. Both families are open source.

## IBM Plex Sans

- Source: https://github.com/IBM/plex
- Licence: SIL Open Font License 1.1
- File: `ibm-plex-sans-latin.woff2` (Latin subset, weights 400/500/600)

## Source Serif 4

- Source: https://github.com/adobe-fonts/source-serif
- Licence: SIL Open Font License 1.1
- Files: `source-serif-4-latin.woff2` (Roman), `source-serif-4-italic-latin.woff2` (Italic)

The WOFF2 files are the Latin subsets served by Google Fonts. The typefaces
remain under their original licences; this repository only redistributes the
unmodified font files.
